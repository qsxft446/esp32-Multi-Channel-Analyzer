DIY gamma spectrometer on ESP32-S3 and AD9226

An open source multichannel pulse-height analyzer (MCA): ESP-IDF firmware, built from off-the-shelf modules, spectrum and oscilloscope in the browser.

Sources on GitHub Documentation

What it is

The device measures the energy of gamma quanta from a scintillation detector with a photomultiplier and builds a spectrum. The pulse from the preamplifier goes straight into a 12-bit AD9226 ADC; the ESP32-S3 hardware (the LCD_CAM camera interface plus DMA) takes the stream and the second core processes it. No sound card is needed, and the count rate reaches tens of thousands of pulses per second.

Features

  • 1–20 MSPS sampling, 12 bits, a continuous stream without gaps.
  • Trapezoidal filter (Jordanov–Knoll algorithm) on ESP32-S3 vector instructions, pile-up rejection, dead time.
  • Spectrum of 2048/4096/8192 channels, peak analysis: centroid, FWHM, resolution.
  • Spectrum export: XML (opens in BecqMoni), CSV, N42 (ANSI N42.42), SPE (SpectraLine).
  • Oscilloscope with edge and amplitude triggering, time base up to 32768 samples, frames over WebSocket with lossless compression.
  • CPS monitor: a 6-hour history, a plot with averaging and a moving average, CSV export.
  • MCA emulation on the serial port using the shproto protocol — PC programs such as BecqMoni see it as a regular analyzer.
  • Network: WiFi or Ethernet (WIZnet W5500 module), time over SNTP.
  • Web interface in English and Russian, no software to install.

What it is built from

PartWhat it is
ESP32-S3-N16R8module with 16 MB flash and 8 MB PSRAM
AD9226ready-made 12-bit ADC board, up to 65 MSPS
DetectorNaI(Tl) scintillator with a photomultiplier and a preamplifier
OptionalWIZnet W5500 Ethernet module

No PCB layout and no fine SMD soldering: everything is wired from off-the-shelf modules.

Inside the firmware

  • Capture: LCD_CAM in camera mode plus GDMA, a ring of buffers in internal RAM.
  • Core 1 processes the stream; core 0 runs WiFi, the web server and the capture interrupt.
  • Write-ups of the causes found while debugging: CLK harmonics inside the WiFi band, the “ADC rate + router channel” pair, the TCP send buffer, lost chunks.
  • Python models of the processing and tests: tools/test_dsp.py.
